# Section A — Group Trip Planner: components map

| | Trigger | Input | Context | Processing | Output |
|---|---|---|---|---|---|
| **Riya** (coordinator) | Wants one trip with 4 friends; tired of chasing | Trip name, month, deadline, names (+ optional phones); adds/removes people and date options any time | Friends live in different cities; plans keep changing | Taps "Send nudge" when the dashboard says one is due; reviews the closest plan if the group is stuck | One shareable WhatsApp link; a dashboard with nudges due, who's in, open maybes, common dates, everyone's swipes, lock status |
| **Friends** (×4) | Open the WhatsApp link (or get a nudge) | Tap their name → ✅/🤔/❌ on date options (🤔 → "when will you know?"), swipe destination idea cards, tap a budget tier (private) + home city, tap hard passes or type their own | Can edit any time; see the group's change feed | Swipe accept / decline on each plan card; tap "I'm confirmed (leave sorted)" | Their answers saved; votes counted; confirmation |
| **Trip planner app** (Next.js on Vercel) | Every page load / every save / every swipe | Everyone's answers, the clock, swipes | Deadline, target month, blend round, lock state | Suggests weekend date options, nudge timing (48h/24h/12h, maybe-due), deadline defaults (counted in, no hard passes, average budget), which date options work for everyone, veto/budget/date checks, change detection → regenerate only broken plans, decision rules (everyone accepts / one blend / closest plan), two-step lock | Pre-filled wa.me nudge links, common dates, valid plan cards, change feed, AGREED → CONFIRMED (frozen) |
| **Gemini** (LLM, free tier) | Trip created (idea cards); then plans: first time, after a split vote, or when a plan breaks | Month (for idea cards); working date options + idea likes + hard passes + group budget ceiling (no individual budgets); for blends, the top plans + swipe results + decline reasons | Rules: 2–4 days inside a window, never touch a veto, stay under the ceiling, tag every veto it touches | Writes 8 idea cards, then 3 plans (or 1 blend / 1 replacement) as structured JSON | Destination, dates, activities, rough cost per person, one line on how it fits each person |
| **Supabase** (database, free plan) | Every read/write from the app | Trips, members, date options + votes, ideas + swipes, preferences, budgets, plans, swipes, changes, nudge log | Row-level security: budgets have no read policy | `set_budget`, `budget_fits`, `budget_ceiling` functions answer only yes/no or a nameless ceiling | Stored state for every page; budgets never leave it |
| **Other API** (optional) | Riya taps "Send nudge" / "Share to group" | Phone number + pre-filled message | No API key — plain `wa.me` links | WhatsApp opens on Riya's phone with the message ready | Friend receives the nudge directly from Riya |
