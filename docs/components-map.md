# Section A — Group Trip Planner: components map

| | Trigger | Input | Context | Processing | Output |
|---|---|---|---|---|---|
| **Riya** (coordinator) | Wants one trip with 4 friends; tired of chasing | Trip name, target month, deadline, 5 names + phones | Friends live in different cities; plans keep changing | Taps "Send nudge" when the dashboard says one is due; reviews the closest plan if the group is stuck | One shareable WhatsApp link; a dashboard with nudges due, who's in, open maybes, common dates, everyone's swipes, lock status |
| **Friends** (×4) | Open the WhatsApp link (or get a nudge) | Pick name → calendar (free / not free / maybe + "when will you know?"), vibes & activities, hard no's, private budget, home city | Can edit any time; see the group's change feed | Swipe accept / decline on each plan card; tap "I'm confirmed (leave sorted)" | Their answers saved; votes counted; confirmation |
| **Trip planner app** (Next.js on Vercel) | Every page load / every save / every swipe | Everyone's answers, the clock, swipes | Deadline, target month, blend round, lock state | Nudge timing (48h/24h/12h, maybe-due), deadline defaults (assume free, no vetoes, average budget), common 2–4 day windows, veto/budget/date checks, change detection → regenerate only broken plans, decision rules (all-5 accept / blend / stuck after 2 rounds), two-step lock | Pre-filled wa.me nudge links, common dates, valid plan cards, change feed, AGREED → CONFIRMED (frozen) |
| **Gemini** (LLM, free tier) | App needs plans: first time, after a split vote, or when a plan breaks | Common date windows + everyone's preferences + vetoes + group budget ceiling (no individual budgets); for blends, the top plans + swipe results + decline reasons | Rules: 2–4 days inside a window, never touch a veto, stay under the ceiling, tag every veto it touches | Writes 3 plans (or 1 blend / 1 replacement) as structured JSON | Destination, dates, activities, rough cost per person, one line on how it fits each person |
| **Supabase** (database, free plan) | Every read/write from the app | Trips, members, availability, preferences, budgets, plans, swipes, changes, nudge log | Row-level security: budgets have no read policy | `set_budget`, `budget_fits`, `budget_ceiling` functions answer only yes/no or a nameless ceiling | Stored state for every page; budgets never leave it |
| **Other API** (optional) | Riya taps "Send nudge" / "Share to group" | Phone number + pre-filled message | No API key — plain `wa.me` links | WhatsApp opens on Riya's phone with the message ready | Friend receives the nudge directly from Riya |
